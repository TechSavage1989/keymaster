# Keymaster 0.1.0 alpha 4

## Interface modernization
- Replaced the crowded settings pane with a larger viewport, compact tool rail, contextual Model/Cut/Keys/Parts settings and a consistent, dark desktop theme.
- Added drag-and-drop STL/OBJ loading and keyboard shortcuts for import, preview, export and frame-camera controls.
- Added a responsive position slider for moving the visible cut plane without rerunning the Boolean cut on each movement.
- Added resin and FDM fit presets, manual clearance overrides, cut-plane key markers, and individual part visibility controls.
- Improved mesh details, file feedback and retaining camera position when changing plane coordinates.

## Packaging
- Build a stable-name Keymaster.exe with an original multi-resolution icon embedded at compilation.
- Install only the needed PySide6 Essentials/Addons instead of the metapackage; replace PyInstaller's broad VTK/PyVista collect-all directives with explicit renderer imports.
- Track the final Windows ZIP size and verify SHA256 checksums before publishing. The previous alpha 3 ZIP was 185,620,332 bytes; this release reports the actual new size.

## Unchanged
- Manifold3D cutting engine, STL/OBJ validation, matching integral pegs/sockets, model-safe exports, settings and user-controlled update notification.
- Existing release assets remain available.

## Remaining limitations
- Preview: the cut plane is axis-aligned; no arbitrary-angle gizmo yet.
- Click-to-place keys project a model surface point to the plane; they are not directly dragged on the cut face.
- Heavy Boolean operations still run synchronously and may briefly block the UI on dense models. Live plane movement is display-only.
- No automatic installer/rollback, mesh repair or physical printer-fit guarantees.
- Headless Qt tests and Windows CI packaging do not replace manual GPU rendering and user acceptance testing.
