# Keymaster 0.1.0a1 preview

Initial Windows-first prototype for cutting a watertight STL or OBJ mesh into two closed parts with matching alignment pegs and sockets.

## What's new
- Axis-aligned cutting plane with position in model coordinates.
- Round and square integrated keys and radial/axial socket clearance.
- Manually positioned keys, a suggested key location, and viewport pick projection.
- Exploded preview of both cut pieces.
- Separate STL export with overwrite protection and validation.
- GitHub update discovery with user-controlled release opening.

## Important limitations
Preview status. No automatic update installation, download/rollback or digital signature. Import requires a watertight positive-volume source, and model units are interpreted as millimeters. Real-world fit and native Windows application behavior require verification.
