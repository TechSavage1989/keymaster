# Keymaster 0.1.0a2 preview

## Fixed
- Correctly import valid watertight STL files whose adjacent triangles store separate copies of shared vertices. Alpha 1 could incorrectly reject these models as open meshes.
- Merge equivalent STL vertex records during import before manifold validation, preserving face geometry and the existing STL/OBJ export workflow.
- Preserve strict rejection of genuinely open or inverted meshes. OBJ import behavior is unchanged.

## Verification
- Added regression tests for STL round-trip import, genuine open-mesh rejection, and unchanged OBJ imports, including a negative control that reproduces the Alpha 1 failure.
- Locally reproduced the error with a user-supplied repaired sculpture STL and confirmed the corrected processing recognizes the watertight solid. The user model is not bundled or shared.
- Windows CI builds the stable-named portable Keymaster.exe and validates the ZIP checksum. Native UI testing and physical printed-fit testing remain outstanding.

## Important limitations
This is a prerelease. No unattended update download/installation, rollback, or digital signature. Models must be correctly scaled in millimeters; cutting is currently limited to one axis-aligned plane per operation. Other mesh repair issues and real-world key fit may require additional work.
