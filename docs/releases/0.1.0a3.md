# Keymaster 0.1.0 alpha 3

## Fixed
- Importing a valid STL could still leave the UI at "No model loaded" after alpha 2. This happened because the import handler incorrectly accessed a nonexistent third row of mesh bounds after validation.
- Correct the model's 3D bounding-box center and each X/Y/Z axis midpoint used by the cutting plane.
- Initialize model and cut-plane controls without premature signal callbacks, so a valid model is displayed and the model name, triangle count and dimensions are shown.
- Show explicit warnings if the 3D preview cannot initialize, instead of leaving an unreported Qt callback failure.

## Validation
- New headless Qt UI tests import a closed STL via a simulated file picker, confirm model label and rendered actors, test all cutting axes and coordinate changes, and cover failure handling.
- Includes negative control reproducing the prior row-index error.
- Geometry regression tests continue to cover real closed vs open STL geometry and matching key operations.
- GitHub CI builds the Windows portable application with the unchanged stable Keymaster.exe name and validates its ZIP and SHA256 checksums.

## Important limitations
Preview build; actual desktop GPU interaction and physical key fitting still require user testing. No automatic installer, updater rollback, mesh repair, 3MF imports or arbitrary angled cuts are implemented.
