# Keymaster 0.2.0 alpha 1 - selective cutting preview

This is a major experimental workflow release. It retains the stable-name Keymaster.exe and the non-destructive source model policy.

## Added
- Free-angle 3D cut-plane move and rotation handles in the viewport (VTK plane widget).
- Bright intersection outline that marks where the real mesh meets the plane.
- Studio clay, lit solid, shaded edges, X-ray and wireframe viewport modes for inspecting sculpt details.
- Deliberate section detection for independent positive-side solids after cutting. Users can uncheck individual detachable sections so they stay joined to the retained negative body.
- Multiple detached printable STL parts from one cut when candidate sections are independent.
- Automatic placement of several spaced alignment keys on a chosen cut surface.
- Tapered alignment keys and an experimental barbed snap-style connector in addition to round and square keys.
- Optional mating face gap for complete cuts, plus existing independent radial and axial socket clearance.

## Important limitations
- Selective detachment only works on *independently connected components* resulting from the selected cut. It cannot arbitrarily sever one part of a fused positive-side region. Rotating/repositioning the cut plane may yield more independent pieces.
- Face gap requires all sections to be cut; unselected sections that must remain attached require zero face gap.
- Experimental snap catches have no material fatigue or cantilever relief simulation and might be unsuitable for rigid materials or resin. Print a small fitting test before using them in a large sculpt.
- Cut analysis/Boolean operations still run synchronously in the initial preview. Very high polygon meshes may pause the UI.
- No automatic mesh repair, project-history stack, brush-based segmentation, real snap-mechanics validation, 3MF import or unattended update installation.
- Native Windows GPU and user printer fit testing remain necessary after automated builds and geometry/unit tests.

## Release validation
The Windows portable bundle is built by the approved GitHub Actions workflow with a compiled embedded icon and SHA256SUMS.txt. Never call a release ready if CI, asset upload, tag identity or checksum verification has not passed.
